# 任务开始轻量回查（对话场景识别）

目的：接到任务先识别本次场景，让已确认偏好与 S2 经验在同类任务开始时到位。
性质：提示级，不强制；无命中不展开、不追问；本清单不创建定时任务。

## 何时执行

- 新会话接到任务、准备给出实质性方案或开始执行前，做一次轻量回查；
- 紧急/简短消息、用户明确要求直接执行、或技能文件不可读时，可跳过并如实说明。

## 步骤（约 1 分钟内，超时即停）

1. 看第一条用户消息判断场景：scope 取 work/personal/general；module/category 按实际内容
   自由归类（不确定先用 general 或按关键词检索，不猜测新词表）。
2. 运行 `query --component s1 --scope <范围> [--module <场景>]` 只读回查；关键词可空格分隔
   （AND），也可加 `--fuzzy` 兜底；旧 v4 原文用 `legacy-search`。
3. 命中已确认偏好（含 user-explicit 事件）：按 scope/text 直接应用，不逐条复述。
4. 命中候选/待验证推断：对照验证信号，本次实际表现留到收尾作证据，不自行定类计分。
5. 命中 S2 候选：收尾按 observe-s2 登记现场，不直接宣称已避免。
6. 没有命中：继续任务，不展开；技能不可读时说明限制，不得声称已回查。

## 输出原则

- 命中偏好只影响行为与表述，不把回查过程写进最终答复；
- 工作与个人生活的相反偏好按现状分开呈现，不自动合并；
- 收尾默认沉淀见 [工作流](workflow.md)“对话生命周期”。
