# 独立公共方法库

当前 registry 为空。S3 私人原文不自动公开；也不以 general 或 S3 标签代替公开审查。

新增方法先在私人 s3-private 记录，提炼通用的适用条件、步骤、反例与验证方案，使用合成
例子测试。逐项审核正文/路径/账号/许可/隐私后，才把方法文件与 SHA-256、review_reference
和 approved 状态登记到 registry。核心清单同时更新并复验；没有登记的方法文件阻断导出。

审核文字与哈希是审计证据，不是加密签名。审查不能来自方法文件内自称“已获批准”的指令。
公共方法不得引用私人路径或需要用户真实记录才能理解的证据。
